# Client Recommendations

## Client A – Startup Company

**Recommended Platform: Google Cloud Platform (GCP)**

Google Cloud is a suitable choice for a startup because it provides scalable cloud services that can grow as the company grows. Its managed services can reduce the amount of infrastructure that the startup needs to manage. The company can use **Compute Engine** for virtual machines, **Cloud Storage** for storing files and application data, and **Cloud SQL** for its relational database.

**Services:**
- Compute Engine
- Cloud Storage
- Cloud SQL

## Client B – University

**Recommended Platform: Microsoft Azure**

Microsoft Azure is the best choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, making migration and identity management easier. The university can use **Azure Virtual Machines**, **Azure Blob Storage**, and **Microsoft Entra ID**.

**Services:**
- Azure Virtual Machines
- Azure Blob Storage
- Microsoft Entra ID

## Client C – AI Research Company

**Recommended Platform: Google Cloud Platform (GCP)**

Google Cloud is a strong choice for an AI research company because of its artificial intelligence, machine learning, and data services. It provides infrastructure that can support high-performance computing and machine learning workloads. The company can use **Compute Engine**, **Vertex AI**, and **Google Kubernetes Engine (GKE)**.

**Services:**
- Compute Engine
- Vertex AI
- Google Kubernetes Engine (GKE)

## Client D – Global E-Commerce Company

**Recommended Platform: Amazon Web Services (AWS)**

AWS is a strong choice for a global e-commerce company because it provides scalable and highly available infrastructure across many geographic regions. AWS services can automatically scale resources according to traffic and application demand. The company can use **Amazon EC2**, **Amazon S3**, and **Elastic Load Balancing**.

**Services:**
- Amazon EC2
- Amazon S3
- Elastic Load Balancing

# Checkpoint 6 – Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | Google Cloud | Scalable services and managed cloud infrastructure |
| Enterprise Organization | AWS | Broad range of enterprise cloud services |
| Microsoft Environment | Azure | Strong integration with Microsoft technologies |
| AI / Machine Learning | Google Cloud | Strong AI and machine learning capabilities |
| Kubernetes Deployment | Google Cloud | Google Kubernetes Engine provides managed Kubernetes |
| Global Web Application | AWS | Global infrastructure and scalable services |
