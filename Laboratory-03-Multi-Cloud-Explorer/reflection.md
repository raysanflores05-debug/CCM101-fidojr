# Mission 3 Reflection

## 1. Which cloud platform impressed you the most?

The cloud platform that impressed me the most is Google Cloud Platform (GCP). I found GCP interesting because of its strong capabilities in Artificial Intelligence, Machine Learning, data analytics, and Kubernetes. I also learned that GCP provides services that can support organizations that work with modern applications and large amounts of data.

## 2. What similarities exist among AWS, Azure, and GCP?

AWS, Microsoft Azure, and GCP are similar because they all provide cloud computing services such as virtual machines, object storage, databases, networking, and identity management. They allow organizations to use computing resources without having to maintain all of the physical infrastructure themselves. All three platforms also provide scalable services that can support different types of applications and businesses.

## 3. How do business requirements influence cloud platform selection?

Business requirements are important because there is no single cloud provider that is best for every organization. A company should consider its budget, existing technology, performance requirements, security needs, location, scalability, and type of application. For example, a university that already uses Microsoft technologies may benefit more from Azure, while an AI-focused company may prefer GCP.

## 4. What did you learn from acting as a Cloud Solutions Consultant?

I learned that choosing a cloud provider requires more than simply selecting the most popular platform. A Cloud Solutions Consultant needs to understand the client's requirements and compare available services before making a recommendation. This activity helped me think about cloud computing from a business and technical perspective.

## 5. How has your GitHub Cloud Computing Portfolio improved after completing this mission?

My GitHub portfolio became more organized and complete after Mission 3. I added research about AWS, Azure, and GCP, a comparison of their services, client recommendations, Linux investigation results, and documentation. I also practiced using Markdown and maintaining my work in a structured GitHub repository.
