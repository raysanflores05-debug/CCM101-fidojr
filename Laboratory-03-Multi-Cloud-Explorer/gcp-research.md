# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform provided by Google. It offers services for computing, storage, databases, networking, artificial intelligence, machine learning, analytics, and application development.

## Global Infrastructure

Google Cloud operates a global infrastructure consisting of regions and zones. Regions are geographic locations, while zones are deployment areas within regions that help provide reliability and high availability.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to create, configure, monitor, and manage Google Cloud resources and services.

## Four Core Services

1. **Compute Engine** – Provides scalable virtual machines for running applications and workloads.
2. **Cloud Storage** – Provides scalable object storage for data and files.
3. **Cloud SQL** – Provides managed relational database services.
4. **Google Kubernetes Engine (GKE)** – Provides managed Kubernetes clusters for containerized applications.

## Three Advantages

1. GCP provides strong artificial intelligence and machine learning capabilities.
2. GCP has strong support for containers and Kubernetes.
3. GCP provides a global infrastructure designed for scalable applications.

## Typical Enterprise Use Cases

GCP is commonly used for artificial intelligence and machine learning, data analytics, containerized applications, web applications, databases, and large-scale data processing.
